## Publish

1. Create a GitHub repository, e.g. `naiju-portfolio`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch → main → / (root)**.
5. Save.

The portfolio uses `Naiju-CV.pdf` and `naiju.jpg`, so keep those files in the repository root.
